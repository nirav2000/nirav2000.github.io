How do the translators work?

Google and DeepL: open their official translator, copy the result, then paste it into the matching card. With a connected secure API, use Translate / compare to retrieve actual provider results. Apple: run the one-time Apple Shortcut or copy the original into Translate/Safari and paste back the result. Browser apps cannot directly invoke Apple's native translation API. No invented provider output is displayed.

Apple Translate · one-time setup

On iPhone, iPad or Mac, open Shortcuts and create these two shortcuts. Use the exact names below. Each should take Shortcut Input, translate it using the Translate Text action, and return the translation with Stop and Output (or the last action's text result).

Translation Lab EN-FR

Translate Text: English to French.

Translation Lab FR-EN

Translate Text: French to English.

Test each shortcut in Shortcuts first. The app invokes Apple's documented x-callback-url and matches the returned result to the original stage. Safari may ask for permission to open Shortcuts. If callbacks fail (e.g. standalone Home Screen app), add Copy to Clipboard to the shortcut, then return here and press Paste. The translation may be present in the callback URL briefly before it is removed. Apple callback documentation.

Account and cloud history

Use your existing App Monitor passkey or authorised kk-syllabus account. Only enable cloud sync on a trusted device; the app stores learning text locally, and all Pages apps share the same browser origin. No account is needed for manual translations.

Local only · no cloud connection verified

Guest history is never uploaded without this consent. Disconnecting stops sync and retains local history. Firebase rules are not changed by this app. If the deployed rules deny access, the app remains local-only.

Automatic translation and in-app explanation

Translation Lab uses your dedicated, owner-authenticated Cloudflare Worker. Google Cloud, DeepL and Workers AI availability are checked against the server. Your credentials stay in the existing services; no API key is required in this page.

Google Cloud results are identified separately from the consumer Google Translate website. DeepL API is optional. In-app AI may make mistakes and is never called without your explicit request.

Local data

Export your history and draft to JSON before clearing browser data. A local draft is saved automatically when you type. No automatic upload of live drafts or screenshots.
